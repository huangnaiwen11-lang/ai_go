# 外部依赖验收门禁

本文档只描述本地代码完成后，进入测试环境或生产灰度前必须补齐的证据。当前不包含任何密钥、真实地址或生产操作命令。

## 阶段门禁

| 阶段 | 必须提供的证据 | 未满足时的处理 |
| --- | --- | --- |
| OAuth / 短信 | 测试供应商配置、回调 state、过期与重复使用、账号升级同一用户、旧会话失效 | 保持 `LocalBindingVerifier`，Go 不接真实回调 |
| PayCores | 测试商户、请求/回调双 HMAC、nonce 重放、订单幂等、退款和账本对账 | 保持 `local_only`，不创建真实订单 |
| Apple / Google | 沙盒回执、服务端验签、重复交易、退款和跨平台商品映射 | 只接受 `local:v1` 回执 |
| 生成中台 | 测试租户、三种原子提交、独立回调地址、回调签名、失败冲正、审核没收 | 使用本地生成中台模拟器，不切换流量 |
| Redis SSE | 测试 Redis、跨进程发布、断线重连、`Last-Event-ID` 补偿、用户隔离 | 使用进程内 SSE Hub，路由默认关闭 |
| 生产灰度 | 监控指标、告警阈值、对账结果、回滚开关演练和负责人确认 | 不部署、不切流 |

## 本地验收入口

在完成代码变更后运行：

```bash
make verify-local
```

该命令只执行 Go 编译、本地合同测试、阶段 0 审计、迁移矩阵和新前端 Go-only 检查，不连接任何外部服务。

## 证据要求

- 真实依赖验收必须使用脱敏请求/响应摘要，不提交密钥、令牌、完整回执或用户数据。
- 每个阶段必须同时保留成功、失败、重试、幂等和回滚证据。
- “本地合同通过”不能替代“真实依赖通过”，也不能直接授予流量切换权限。
- Animate 继续 Node-only；本次不为 Animate 新增 Go 路由、写入方或结算职责。
